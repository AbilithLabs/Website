# Abilith website

Concept site for Abilith, a somatic computing company, and its first system, Hermes: a knit sleeve that runs from the fingertips to the shoulder. The home page is a single static page with a scroll-driven Three.js scene of Hermes. A Resources section publishes the white paper.

The home page follows the white paper: the problem (knowledge scales, skill never has), somatic computing and its loop, Hermes in four chapters (Sense, Fit, Guide, Learn) with its three modes and its parts by zone, the skill library, the four principles, the thesis, the white paper card, and the close.

## Layout

- `src/page.html`: markup, styles and page script. `/*SCENE*/` and `<!--IMPORTMAP-->` are filled in at build time. Its nav, footer and shared styles are reused by the Resources pages.
- `src/scene.js`: the procedural 3D arm and Hermes sleeve (Three.js 0.160). The intro shows the hand resting on a table; the chapters raise the arm into profile (`setStance`). Camera framing for each chapter is in `KF`.
- `renders/`: pre-rendered stills (editorial frames, storyboard fallback for reduced motion / no WebGL, hero poster).
- `public/`: the built site that Vercel serves. Don't edit it by hand.
- `tools/`: build script and render/QA helpers.

## Resources and the white paper

- `/resources` lists papers and notes, and `/resources/white-paper` is "Somatic Computing: Abilith White Paper". Both pages are generated by `tools/build_paper.py` and share the home page's tokens, nav, grid, buttons and footer, read from `src/page.html`.
- `src/white-paper/paper.md` is the website copy of the paper. The working draft is the Claude Doc at https://claude.ai/artifact/74dFZVYw3Ari7PXxcaLK73, so edit there first, then mirror the change here. Citations like `[12]` link to the numbered Sources list, and the build fails if a citation has no source.
- `src/white-paper/figures/fig-N.jsx` are the paper's six figures, the same code as in the doc. `node tools/render_figures.cjs` (after `cd tools && npm install`) turns them into the `fig-N.svg` files that the page inlines.

## Build

```
python3 tools/build.py
```

This writes `public/index.html` and `public/resources/`, and converts `renders/*.jpg` to `public/img/*.webp` (if Pillow is installed). Commit `public/` as well, because Vercel serves it as-is with no build step.

## Re-render stills and preview locally

```
cd tools && npm install && cd ..
python3 -m http.server 8765
# preview: http://localhost:8765/tools/index-dev.html
node tools/stills.js '[{"w":1600,"h":1000,"still":"music","stance":"table","out":"renders/music.jpg"}]'
```

The stills are `music`, `cooking` and `object` (all with `"stance":"table"`). Storyboard frames (`renders/sb-*.jpg`, shown with reduced motion or without WebGL) use `{"region":"seq","p":0.2,"center":true}` (Sense), `0.4` (Fit), `0.66` (Guide) and `0.86` (Learn), at 1200x900. The hero poster uses `{"region":"hero","p":0}` at 1920x1080. Re-render the storyboard after changing a camera keyframe.

`node tools/qa.js 1440 900 desktop` (add `reduce` for the storyboard) screenshots every section into `tools/out/qa/` and reports sideways overflow. `tools/seq.js` takes sequence screenshots.

All imagery is concept renders. Hermes is in early development and isn't working hardware, and the figures on the site are design targets.
